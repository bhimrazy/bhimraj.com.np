# bhimraj.com.np

![bhimraj.com.np social preview](https://bhimraj.com.np/opengraph-image)

Personal site of Bhimraj Yadav, software engineer in Kathmandu: [bhimraj.com.np](https://bhimraj.com.np).

## What's on the site

- **Blog**: long-form posts on machine learning and software engineering.
- **Projects**: write-ups of side projects and experiments.
- **Open source**: contribution stats, pulled from a daily snapshot of GitHub data.
- **Research**: my IEEE Access paper and a short reading list.
- **Resources**: a reading and watching list of courses, books, talks and papers, with progress tracking on course pages.

## Built with

Next.js 16 (App Router), React, Tailwind CSS v4, shadcn/ui, Content Collections, Resend, PostHog, Biome and Vitest, in a Bun and Turborepo monorepo.

## Development

Setup, commands, layout and environment: [docs/development.md](docs/development.md).

Deployed on [Vercel](https://vercel.com); every pull request gets a preview deployment.
